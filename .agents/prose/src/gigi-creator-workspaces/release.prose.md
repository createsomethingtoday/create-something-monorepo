# Deliver GiGi creator workspaces

### Parameters

- The current CREATE SOMETHING Rust/Tauri GiGi desktop app, identifier `agency.createsomething.gigi`, and authenticated integration broker.
- Reviewed source and the existing qualified DMG distribution path.
- Grantbot repository as prior art only; it is not the deployment target.

### Returns

- A source-bound review and validation report, updated app and DMG, qualified release receipt, and independently checked download distribution; or exact unfinished gates.

### Requirements

- Users can save and revise Instagram drafts with caption, media preview, account status and actionable validation. Only explicit confirmation of the saved revision/account/payload can request publishing. Drafts work without an account connection.
- The host durably records publish intent before dispatch. Ambiguous outcomes block duplicate execution and require reconciliation. Only provider readback establishes publication. Tokens remain in the broker; no developer credential is distributed in the DMG.
- Local music uses explicit selected files/folders, metadata, search/filtering, projects, collections, versions and playable previews for supported media. Originals remain untouched. No private media is uploaded or unrelated folders scanned. Missing/replaced files require explicit recovery and identity checks.
- The existing app navigation, linked records, backups, subscribed agent and CTX setup continue working. CTX credentials remain unchanged.
- OAuth creation or scope expansion needs an explicit user action. Development never publishes a test post or performs new grants. Documentation is not a permission boundary.
- Independent lanes own local music, social draft UI/persistence, and provider integration. The coordinator integrates shared routing and style; a separate reviewer checks the completed diff.
- Validate Rust domain operations and JavaScript behavior using synthetic data, compile the app, inspect native UI, then qualify Developer ID signatures, notarization, Gatekeeper, and exact DMG-contained app identity. Verify immutable download bytes and the production download page separately. A local test or build cannot establish production acceptance.

### Errors

- Missing access or release inputs must identify the exact pending action and target, preserved work, and denied/pending/uncertain outcome. Continue independent work.
- A failed check or unresolved review finding prevents release claims. A completed run is not proof these requirements were satisfied.
