# Brand truth and flexible motion

Repository sources, inspected 2026-10-05:
- packages/canon/src/lib/styles/tokens.css: performance paper #f3f3f0, ink #090909, muted #5e6268, line #d7d7d2, signal #0057b8, growth #007a4d. Semantic status must have words as well as color; green is not a generic decoration or a substitute for evidence.
- packages/canon/src/lib/brand/marks/RingMark.svelte: viewBox 0 0 100 100, circles (53,50,r41.5) and (43.5,50,r31.5), no fill, currentColor stroke 8.5.
- packages/ltd/static/brand/create-something-wordmark-white.svg: exact outlined Arial Bold wordmark, -0.015em tracking. Reuse supplied asset rather than retyping a substitute.
- tokens.css font-performance-sans begins Geist Variable and falls back to Arial/Helvetica; font-performance-mono begins IBM Plex Mono. Existing local Arial and IBM Plex Mono are appropriate for this review sample. This is not a global font replacement.
- docs/CREATE_SOMETHING_PERFORMANCE_LAB_DESIGN_LANGUAGE.md: operating artifacts, clear hierarchy, square action geometry, restrained semantic color. Avoid decorative glow, gradients, generic card stacks and elastic/bounce motion.

Review geometry at the actual output size. Align on a simple consistent grid; leave sufficient whitespace around large type, diagrams and evidence. Label illustrative states as unverified rather than inventing acceptance. Use blue for focus/signal only with clear scope wording.

Token UI durations (100/200/300/500/700ms) describe interface transitions, not mandatory educational timing. An explanatory traversal may take longer where understanding benefits. Avoid mechanical animation at every clause. Use transforms and drawn relationships when useful; use static holds or cuts when clearer. Inspect mid-motion readability, not only beautiful endpoint stills.

V2 audit: olive/lime palette departed from ink/paper semantic tokens; rounded station cards softened square operating geometry; system-ui headers at weight 500 did not carry supplied wordmark/Arial Bold hierarchy; long camera travel and underspecified evidence icons competed with teaching; the compact language thought group inherited rushed narration. New sample replaces these with a single useful outcome, a restrained four-decision route and one bounded scope consequence. The mock site remains illustrative.
