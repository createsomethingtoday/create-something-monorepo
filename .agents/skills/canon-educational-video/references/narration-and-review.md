# Narration direction and review gates

Opening pattern: useful destination → pathway → first decision. Closing pattern: synthesis → unresolved edge or prerequisite → transfer to the next judgment. These are editorial relationships, not fixed scripts.

Prefer short complete sentences and natural contractions. Say what the learner will inspect or decide, avoiding universal productivity promises. Put affiliation and AI voice context in a concise course-info disclosure. A voice recording with rejected delivery remains provisional even if its words were once accepted.

For Descript, restrict changes to controls visible/documented in the authorized environment. Separate script rewrite, pauses, pronunciation, voice identity and any available delivery/model controls in the A/B plan. Do not invent tone sliders or assume cross-project media access. Record project-specific access failures in dated project notes rather than turning them into permanent skill restrictions.

A/B listening plan: establish authorization before recording. A uses revised script with sentence breaks and unhurried pauses using the existing voice and settings. B uses the same words and voice, adjusting only a delivery control confirmed available at execution time, or a clearly specified alternative variable (for example pause placement) if no such control exists. If A already varies pauses, choose a different supported variable or postpone B; do not label identical treatments an experiment. A human recording may be compared when authorized. Keep sample, loudness and playback conditions comparable. Human scores conversational delivery, meaning, pronunciation and room for visual holds; do not manufacture a passing score. Existing stiff recording is a baseline, not the desired result.

Gates: source valid; render technically valid; visual sequences reviewed; real-time playback checked; voice listened to and accepted; factual/disclosure review; release authorized. Report each as pass, pending or blocked with evidence. No blanket acceptance from technical checks.
