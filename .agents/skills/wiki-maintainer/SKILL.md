# Maintain the company wiki

Start with one real request and the decision the guidance should help someone make. Use the [company operating wiki](../../../docs/COMPANY_OPERATING_WIKI.md) as the normal entry point. Scope the work to the affected decision in marketing, development, socials, future casting, or another documented company workflow.

## Trace the decision

Preserve the original request, the entry point the operator had, what the agent actually did, and the correction or dated source change. Use a bounded CTX search for earlier rationale and inspect the event. Verify the decision against the owning artifact, its revision and, for current external claims, the live source. Identify the first step where an agent could reasonably take the wrong route. If evidence is missing or conflicting, record the open question and who can settle it.

## Pick the smallest repair

- If a link is missing, fix the route. If a procedure is stale, amend its owning playbook or skill and link there. Update a generated wiki through its owning generator or inputs.
- For a changing fact, document where to retrieve it. Keep private client material in the authorized workspace and record only a safe reference or retrieval instruction in shared guidance.
- If the existing path already answers the question, cite the exact passage, record the missed step and replay it without editing. A single assignment-specific correction belongs with that assignment until there is evidence that it generalizes.

## Replay without coaching

Before the replay, privately write the expected decision, evidence standard, acceptable alternatives and permission boundary. Give a fresh agent the original request, ordinary entry point and authorized delivery scope. Withhold the rubric, correction, chosen example and previous answer. A worked example already visible in the wiki stays visible; require a new decision or artifact to distinguish reuse from copying. If a replay would cause an external effect, exercise the draft or read-only stage unless the actual action is authorized.

Inspect the evidence and the actual deliverable. Can you trace the claim to a current permitted source? Did the agent use the right procedure and stop at the right stage? For visual work, inspect the export at its intended size. Link or projection checks establish document integrity; the task replay establishes whether the guidance worked for this case.

Keep a short receipt in the existing work record: request, starting route, evidence and date, edit or reason for leaving the wiki alone, replay output, verdict and remaining limits. If the agent still guesses, repair the demonstrated gap and replay the affected decision with fresh context. Stop on a passing replay or an identified blocker. If independent replay is unavailable, record it as untested.
