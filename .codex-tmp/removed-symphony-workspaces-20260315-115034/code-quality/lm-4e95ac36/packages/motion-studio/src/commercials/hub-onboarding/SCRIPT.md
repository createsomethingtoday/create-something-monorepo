# SCRIPT.md — HUB ONBOARDING COMMERCIAL

## Audio Notes

**Duration**: ~62 seconds of voiceover inside an 80 second commercial  
**Voice**: Adam style delivery. Calm. Direct. Clear.  
**Style**: Senior in high school reading level. Short sentences. One idea at a time.  
**Product**: `.agency` Hub MCP onboarding for first-time client users

---

## Voiceover Script

[SILENCE 2s]

You just got access to a Hub MCP.

One sentence version.

It is a secure bridge that lets your AI app use approved tools.

[PAUSE 1s]

You get your own lane.

That lane comes with a Hub URL, a bearer token, and an approved host.

In this example, the host is Codex.

Claude Desktop and Cursor follow the same pattern.

[PAUSE 1s]

To connect it, paste the Hub URL and token into your host config.

Then your app can talk to the Hub.

[PAUSE 1s]

Start with one safe question.

What tools do I have access to in this Hub?

First, the Hub finds the right tool.

Then it checks what that tool needs.

Then it runs the approved action.

[PAUSE 1s]

Here is the part to remember.

Safe actions run fast.

Risky actions ask for review.

Blocked actions stop with a clear reason.

[PAUSE 1s]

If the connection breaks, do not guess.

First, check the connection.

Then ask the Hub for the repair link.

Reconnect.

Retry the same action.

[PAUSE 1s]

Connect once.

Start with one safe workflow.

Ask for review when the system tells you to.

[END]

---

## Voice Direction

- Keep it calm and plain.
- Do not sound impressed by the technology.
- Explain each step like you are showing a classmate how to start.
- Put slight emphasis on: "secure bridge", "safe question", "ask for review", and "do not guess".
