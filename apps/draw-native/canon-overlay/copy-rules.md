# Draw Native Paired Canvas Copy Rules

- Say `Mac authority` for the canonical owner and `iPhone companion` for the input surface.
- Use `Pair`, `Linked`, `Offline`, `Queued`, `Reconnect`, `Synced`, `Revoked`, and `Expired` consistently.
- Put the certificate fingerprint beside the pairing decision and the revision beside synchronization claims.
- Never describe queued iPhone work as committed until the Mac returns an applied receipt.
- Say `Convert to` only for an explicit operator action and state that source material is preserved.
- Do not call unsigned, unnotarized, simulator, or CI artifacts production.
- Spoken and thin-display output names connection state, queue depth, authority, and the next action only.
