# Synthetic workflow demo

For automation consultants and technical leads, answer “Can I correct a workflow and hand off a readable, recoverable map?” by showing one request-to-delivery map. Open on the empty Draw canvas, end on the saved/exported corrected map, and do not imply phone collaboration, cloud teamwork, AI reasoning or native-shell agent control.

The silent recording uses the actual local browser Draw implementation and synthetic content. A capture harness collects `document.modelContext.registerTool` registrations; tool execution invokes the real browser-local inspection, mutation and targeted-revert implementations. No model/provider is connected. This is a technical capability demonstration, not a claim about agent discovery in an unsupported browser.

Beats: create three connected steps; correct “approve every request” to a human-review decision; apply title, body, bullet and selected emphasis; save; inspect and apply a proposed tool edit; inspect its changed state and revert by change ID; export editable JSON and SVG/PNG; reload and show retained work. The product’s action/results remain visible. No synthetic product pixels, cropped-away errors or speed claims.

Original WebM is retained. MP4 is a format conversion only, silent, uncut, with no time compression. `receipts.json` records tool inputs, results, revision-bearing change receipts and observed beat times. The handoff JSON and SVG/PNG exports are inspectable files. This browser demo supplements, rather than replaces, the previously completed exact packaged Mac GUI acceptance.
