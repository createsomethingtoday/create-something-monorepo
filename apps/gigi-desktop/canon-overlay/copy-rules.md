# GiGi copy rules

- Use music-work terms: gig or shift, person, location, schedule, task, and money. A source email is an interaction until a user links it to another record.
- Say “incomplete” when money is unknown. Never infer a fee, payment, date, or currency from sparse source text.
- Describe consent precisely: “Start connection,” “Finish consent,” “Verify connection,” and “Import page.” An uncertain connection requires operator review; it is not ready to retry automatically.
- A prepared agent command is setup guidance, not proof that Codex or Claude is connected. Show the last verified local tool receipt separately.
- CTX snippets are supporting history with references. Current records and links come from SQLite.
- Keep status, owner, next action, and evidence close together. Do not promise phone access until the physical cellular session is verified.
