# GiGi Identity policy review — 2026-09-30

Reviewed `packages/identity-worker/src/index.ts` and `test/oauth-application-policy.test.ts` against `packages/gigi-integrations/src/auth.ts` and `worker/index.ts` in this worktree.

The new application policy selects `https://gigi-connector.createsomething.workers.dev` and issues a one-hour application access token whose `aud` and `resource` are that origin. The resolver rejects `/mcp` and unrelated hosts; the existing resolver canonicalizes trailing slashes. The token exchange continues to require a registered public client, matching redirect URI, S256 PKCE, a one-time grant, and an active verified Identity user. Identity userinfo validates the signed application token and rechecks the active user. The desktop verifies the token and userinfo resource and client ID before storing a private session. The broker verifies online userinfo resource, verified email, and an explicit subject allowlist before provider access.
