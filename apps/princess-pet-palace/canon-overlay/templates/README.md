# Princess Pet Palace Overlay Templates

Use these templates to review a child-facing learning surface before it ships.

## Files

- `surface-brief.md`: records the activity, safety boundary, Canon reuse, accessibility evidence, and approval status.

## Template Rules

- Keep the structure stable so reviewers can compare surfaces.
- Keep child-facing story and activity language project-local.
- Do not propose a Canon extension until a shared need has repeated evidence.
