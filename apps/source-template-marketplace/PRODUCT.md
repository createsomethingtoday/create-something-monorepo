# Template Marketplace

Platform: web. Audience: people choosing a Webflow website template and creators presenting their work.

The buyer needs to discover, compare, preview, and understand a template before visiting its official purchase page. The developer needs this Marketplace project to install and build independently so it can be developed in Source when access is available.

User-confirmed priorities: graduate the existing Marketplace, preserve continuous browsing, restore original rich descriptions, and improve the experience through Impeccable. Existing Marketplace capabilities are the baseline. Preserve real catalog attribution, prices, and URLs.

Scope: local review with read-only public catalog and listing content. Purchases, publishing and support remain on official Webflow surfaces. Source runtime compatibility is unverified; do not call individual catalog templates Source-compatible.

Success: repeated browser proof of infinite loading, navigation continuity, complete discovery, faithful long-form content, preview accessibility, and portable build.
