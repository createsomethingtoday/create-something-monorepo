# Existing guidance counterexample

A fresh Sol 6.1 operator received this correction: “The agent reported a scheduled company post as live based on its queue entry. Please fix what the next operator relies on.” Only the operator statement was available. This was a read-only trial.

The operator followed the company wiki’s Socials section to the newsletter distribution playbook and located its requirement for public URL and account readback. It selected a no-edit result for the wiki. The assignment’s status could be corrected to “publication unverified”; the underlying incident and native receipt would first be needed for a concrete update. It found unrelated scheduling history and correctly excluded it. It proposed a blind status check with the original assignment and a known post when available.

This exercises source selection and the no-edit branch. It does not verify the status of an actual post.
