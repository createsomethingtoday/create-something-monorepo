## Decision

Use the Fleet export as the **primary marketing-pattern baseline** and the Evermind export as a
secondary structural reference. Neither export is a copy-exact code foundation.

Fleet is substantially closer to the rendered Performance Lab direction: decisive full-bleed
media, a 12-column editorial grid, large sans typography, technical mono labels, hard contrast,
sticky sequences, and sparse evidence rows. Evermind remains useful for modular rhythm and
responsive section discipline. Their exported implementations are not suitable for direct
propagation across CREATE SOMETHING properties. The aligned ideas should be rebuilt as small Canon
primitives using current Performance tokens, semantic motion, accessibility contracts, and
property-owned content.

The material identity is **controlled water**: flow under designed conditions. This differentiates
CREATE SOMETHING from Dify's earth/rock language while remaining native to workflow governance.

## Water Grammar

Water is useful because it makes governance visible without anthropomorphizing the system.

| Device | Meaning | Preferred imagery | Avoid |
| --- | --- | --- | --- |
| Flow | Work in motion | Flume, channel, directional current | Open-ocean lifestyle image |
| Pressure | Load and real conditions | Jet, impact, compression, spray | Disaster spectacle |
| Boundary | Policy and permissions | Spillway, gate, edge, vessel | A wall presented as the whole system |
| Wake / trace | Evidence after action | Wake line, ripple sequence, residue | Decorative wave pattern |
| Clarity | Inspectable conditions | Waterline, refraction test, droplets on glass | Wellness purity language |
| Turbulence | Exception and ambiguity | Measured vortex, disturbed surface | Generic storm photography |
| Settlement | Resolved state | Calm basin, level line, collected receipt | Empty serenity image |
| Dye trace | Correlation, provenance, run history | Injected marker in a clear channel, dye port, timed dispersion | Colored water as a mood or brand wash |

Clarity, turbulence, and settlement are the three devices that carry inspection, exception, and
resolution. Their absence is why the material layer cannot currently speak to the Judgment tier,
and why campaign sequences end on evidence rather than on a resolved state. Briefs for the four
missing devices live in `docs/PERFORMANCE_LAB_WATER_ASSET_BRIEFS.md`.

Preferred environments are engineered and observable: wave tanks, test basins, spillways, flumes,
laboratory vessels, capillary tests, channel infrastructure, refraction rigs, and controlled impact.
Black-and-white image treatment carries the material layer; semantic color belongs to the operating
layer and remains thin, functional, and redundant with shape/language.

The governing phrase is **governance is the channel, not the dam**. It describes reliable movement,
not restriction for its own sake.

## New Board Review

### Strongest direction

The white/black constitution board is the strongest foundation because it separates:

- brand claims and typography;
- controlled-water field studies;
- workflow and operating-state artifacts;
- public proof canvas;
- issued physical objects.

The black manifesto board is strongest for campaign energy. The darker workflow board is strongest
for a product proof surface. They should become coordinated modes, not one continuous visual density.

### Keep

- Decisive sans-serif headline scale with mono evidence labels.
- Hard panel boundaries and asymmetrical image crops.
- Water terms tied to real operating concepts: pressure, boundary, wake, trace, clarity.
- Workflow map, state, receipt, owner, version, and verification shown as primary objects.
- Physical artifacts such as a system passport, lab report, field notes, and proof receipt.
- Black campaign mode paired with optic-white proof mode.

### Refine

- Replace the synthetic `92%` readiness headline with scoped dimensions and denominators unless an
  explicit scoring method is present.
- Keep semantic category colors as thin rails, rules, nodes, or indexes. RUN / WAIT / STOP require
  language and shape, not color alone.
- Use water photography to describe a condition, never as a generic environmental backdrop.
- Treat generated boards as composition briefs; rebuild all type, graphs, IDs, and receipts as real
  DOM or source-controlled artifacts.

### Reject

- Generated logos, QR codes, dates, receipts, and interface data as evidence.
- A literal water brand, nautical vocabulary, ocean lifestyle, or environmental consultancy tone.
- Saturated blue gradients, glassmorphism, wave-shaped containers, and decorative fluid shaders.
- The implication that governance is obstruction or that one synthetic score explains readiness.

## Circularity Reference Translation

The 89-page workbook is more valuable as a **design method** than as a campaign aesthetic. Its
public principles are material choices, cyclability, waste avoidance, disassembly, green chemistry,
refurbishment, versatility, durability, circular packaging, and new models.

Transfer the method this way:

| Circular design principle | System-design translation |
| --- | --- |
| Design with the end in mind | Define receipt, recovery, and stop conditions before execution |
| Material choices | Choose data, model, tool, and asset inputs intentionally |
| Disassembly | Keep components, policy, automation, and evidence independently replaceable |
| Durability | Preserve stable public contracts and verified behavior |
| Refurbishment | Repair a workflow without discarding its evidence history |
| Waste avoidance | Remove decorative UI and unsupported metrics |
| New models | Create governed delegation and evidence-bearing services |

Transferable visual traits are the rigid page grid, typography as structural content, alternating
black/white modes, narrow metadata rails, numbered principles, and workbook progression. Do not
copy its marks, neon accent, typography, page templates, or wording.

## Marketing Pattern Baseline

Future public-property work should begin from these six composition patterns. They are a reusable
page grammar, not a route template.

| Pattern | CREATE SOMETHING use | Canon or property owner | Required boundary |
| --- | --- | --- | --- |
| Campaign opening | Full-bleed controlled-water/material field study with decisive claim and one operating annotation | Canon field-study/frame primitive plus property copy | Water photography carries kinetic campaign energy; no stock logistics landscape, decorative video, or copied Fleet hero |
| Thesis plus conditions | One large proposition paired with three inspectable conditions or consequences | Property narrative using Canon protocol/state rows | Conditions need owners, denominators, or evidence; no generic benefit cards |
| Sequential field tests | Sticky or chaptered progression through pressure, boundary, trace, and settlement | Canon semantic sequence plus property-owned assets | Motion must preserve reading order and settle immediately under reduced motion |
| Contrast chapter | One black/white or optic-light break that marks a principle or intervention | Performance campaign/lab modes | Semantic color stays a thin functional rail; do not adopt Fleet yellow as brand identity |
| Evidence index | Editorial collection of articles, reports, receipts, or field notes with varied density | Property data and content routes | No empty exported CMS shell or repeated equal-weight card grid |
| Conversion handoff | Final field image or proof object paired with one next action and its boundary | Property route plus Canon proof/delegation primitives | Carry context, owner, and proof into the action; never revert to a generic lead form |

### Adopt

- 12-column editorial alignment with visible gutters and hard section boundaries.
- Fluid display hierarchy paired with compact mono labels and evidence metadata.
- Full-bleed media as a narrative chapter, not a decorative card thumbnail.
- Sparse proposition-plus-three-condition layouts.
- Sticky sequential compositions when they explain an operating progression.
- Explicit style-guide, instruction, changelog, and provenance surfaces.

### Translate

- Fleet's logistics hero becomes an original controlled-water or material field study.
- Sticky image cards become versioned field tests with pressure, boundary, trace, and receipt data.
- Yellow technology chapter becomes a black/white Performance chapter with a thin semantic state
  accent.
- Newsroom slider becomes an evidence index with real articles, reports, dates, and empty-state
  behavior.
- Request-a-quote CTA becomes a workflow-map or booking handoff that preserves owner, authority,
  and proof boundary.
- Webflow reveal/hover sequences become Canon semantic motion with an immediate settled reduction.

### Reject

- Fleet marks, copy, logistics imagery, yellow identity, fonts, and page-specific class names.
- Exported Webflow interactions, jQuery, Lenis, remote GSAP/SplitText, and forced scroll resets.
- Clickable non-semantic containers, missing focus contracts, and content hidden when motion is
  reduced.
- Broken asset paths, repeated responsive source derivatives without provenance, and empty CMS
  placeholders as public UI.
- Treating the 12-column grid as permission to fill every cell; Performance Lab needs controlled
  negative space and a legible evidence hierarchy.

## Consolidated Keep / Translate / Reject Map

### Keep as principles

- A max-width container with explicit page gutters.
- A small spacing ladder shared by section and component layout.
- Full-bleed media slots with intentional object positioning.
- Modular sections that collapse predictably at desktop, tablet, and mobile breakpoints.
- Alternating light/dark chapters and sticky navigation only when it improves orientation.
- Separate style-guide and license/provenance surfaces.

### Translate into Canon

| Evermind idea | Canon target |
| --- | --- |
| `main-container` and page padding | Performance frame/grid token and component |
| 160/120/80 section padding | Responsive Performance section rhythm using existing spacing tokens |
| Image-cover and parallax wrappers | `PerformanceFieldStudy` media primitive with semantic motion intent |
| Cards and feature grids | Protocol, receipt, state rail, and proof artifact components |
| Page-specific hover timelines | Existing motion intent contract with reduced-motion settlement |
| Template light/dark variables | Performance campaign / lab / archive modes |
| Style guide | Canon examples and focused component tests |

### Reject

- Webflow `.w-*` runtime classes and page-specific template class names.
- Remote plugin dependency as the default interaction path.
- Blur-in, parallax, rotation, or marquee motion without operational meaning.
- Serif-led eco-brand voice, soft moss palette, and rounded template navigation.
- Repeated equal-weight marketing cards as the dominant composition.
- Empty alt text for meaningful images, suppressed focus outlines, and autoplay without a reduced
  motion equivalent.

## Foundation Architecture

The cross-property foundation should remain:

1. **Canon tokens** - Performance color, type, spacing, hard-edge radius, and semantic motion.
2. **Canon primitives** - frame/grid, field study, annotation rail, protocol card, state rail,
   proof footer, and system passport.
3. **Property compositions** - route-level narrative and actual evidence.
4. **Property assets** - original water/material imagery with prompt and provenance metadata.

This preserves the polish of a cohesive template without making every property inherit the same
marketing page, runtime bundle, or content density.

## Acceptance Standard

Nothing appears merely because it looks technical or fluid. Every element must signal a condition,
support a decision, direct flow, or leave proof.
