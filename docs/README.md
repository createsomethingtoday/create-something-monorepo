## Directory guide

```text
docs/
├── guides/       how-to guides, operator workflows, reference material
├── internal/     historical plans, retrospectives, internal memos
├── policies/     versioned policy artifacts (.md + .json)
├── patterns/     reusable architectural patterns
├── examples/     small supporting artifacts
└── archive/      older source material retained for traceability
```

## Reading guidance for agents

- Start small. Read the nearest index or policy catalog before opening many files.
- Prefer canonical docs over historical memos when both exist.
- Use `docs/internal/` for context and rationale, not as the first source of truth.
- When a task spans multiple tiers, read one document per tier instead of trying to load everything.
