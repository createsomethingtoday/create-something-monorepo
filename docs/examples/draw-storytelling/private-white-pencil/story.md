# Give the agent a smaller tool.

18-second silent teaching study. A document lookup should expose a read capability. An evaluation deliberately tries an unnecessary write; the initial broad boundary permits it. Narrowing the tool boundary removes the write capability. This is a conceptual example, not a claim of proven enforcement in a deployed product.

0–4.5 s — Start with the task. A white-pencil actor connects to a document. Caption: “Find the document.”
4.5–9 s — Test the boundary. A second path reaches a pencil/write action. Mark it with a muted red cross. Caption: “The test can write, too.”
9–13.5 s — Narrow the tool. Draw a close boundary around the read route. Fade the write branch; its attempted path stops at the boundary. Caption: “Expose only the read.”
13.5–18 s — Test again. White actor takes the read route, document is found; a blocked write branch remains explicit. Caption: “Read succeeds. Write is unavailable.”

Final takeaway: “Teach the boundary, not just the happy path.”

Visual rules: #090909 background; #f3f3f0 strokes and captions; #a6aca7 secondary labels; muted red reserved for overbroad path. Stable labels. Genuine generated pencil actor with three redraws at 8 fps. Sparse irregular stroke diagrams, no decorative movement. Final 2.5-second hold.
