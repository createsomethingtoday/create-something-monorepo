# Current Canon character contract

Canon is squat, tactile and quietly capable. The approved identity uses charcoal
felt, a soft cuboid head, oval cream woven eyes with contained pupils, a stitched
pixel smile, gentle hands and a cream notebook. The digital face is part of the
woven material. It does not become a glass screen or a flat floating face.

The accepted r41 body, r42 head, r45 poses and workshop scenes are recorded in
[the Agency artwork provenance](../../packages/agency/static/images/canon-agency-v1/ARTWORK.md).
Keep these originals unchanged. New task illustrations must preserve this
identity and document their own masters, prompts and review status.

Use the head in its approved optical frame at 96 CSS pixels. Smaller identity
placements use the word Canon. A sprite sheet is an editorial pose collection,
not evidence of an animation rig or a running agent. Keep execution, approval,
failure and completion understandable in the owning interface's text and controls.

Each illustration explains a task. Preserve the comparison, gate, notebook,
connection or handoff that makes the scene useful. A welcome scene does not
automatically explain every task. Keep conceptual illustrations distinct from
actual product recordings, customer evidence and release receipts.

The public websites retain a black foundation, local Geist typography, measured
wayfinding and square composition frames. Warm paper, wood and ceramic belong
inside the illustrations. Heroes and CTAs use CSS backgrounds with essential
headings, links and actions in HTML. Inline art belongs in sections beneath.
Review phone framing separately; do not put copy over a face, hands or task.

Alignment with OpenAI's disciplined typography and approachable design language
is useful for CREATE SOMETHING as Select Partners. Preserve the original Canon
identity and existing approved partner attribution. This is not permission to
add marks or endorsement claims.

CRE-2455 tracks replacement of the remaining older character implementations.
The [retirement manifest](../../config/canon-character-retirement.v1.json)
records positively identified old public assets and their hashes. Git history,
dated proof and historical deliveries remain intact. Run
`node scripts/check-canon-character-retirement.mjs` against current tracked
website assets, and pass `--artifact <deployable-directory>` to check a built
release for copied legacy bytes. These checks establish coverage, not aesthetic
acceptance. Review actual responsive pages and behavior independently before
promotion.
