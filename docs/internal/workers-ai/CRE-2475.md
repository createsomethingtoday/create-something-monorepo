# CRE-2475: Workers AI model compatibility

## Scope

Replace the retired `@cf/meta/llama-3.1-8b-instruct` call in scanner-worker and webflow-apps-audit-agent with active `@cf/meta/llama-3.3-70b-instruct-fp8-fast`.

The current live inference returns a structured object in `response` when the prompt requests JSON. The published schema says string. Both forms must pass through the existing parser. A name-only change is not safe.

## Evidence before deployment

- Both package TypeScript checks pass.
- Six source compatibility tests pass: object/string results and safe error cases.
- Six exact deployed-bundle tests pass: reversible patch equality and full request handlers with mocked AI/DB/KV for object/string results.
- Live model calls using exact prompts from those handlers and synthetic fixtures returned scanner PASS/100 and audit analytics/0.9.
- No customer records were used. Local DB/KV stubs held all test writes.
- Model catalog: active, no planned deprecation. Price: $0.293/M input, $2.253/M output. Context: 24k. This is a larger/more expensive model, selected for matching response semantics with the minimum fix.
