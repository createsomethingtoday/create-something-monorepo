Set up support on your Mac.

For Apple Silicon Macs (M1 or newer). This uses the official RustDesk app to let Micah help with your screen during an agreed support session.

1. Install RustDesk

Open rustdesk-1.4.9-aarch64.dmg from this folder, then drag RustDesk into Applications. Open RustDesk from Applications. If you received this guide without the installer, download the official Apple Silicon installer.

You do not need an account or a paid RustDesk subscription. Leave the “Install” system-service option alone; it enables support at startup and is not needed for these sessions.

2. Allow screen sharing and control

Follow RustDesk’s prompts to enable Screen Recording (called Screen & System Audio Recording on some macOS versions) and Accessibility in System Settings → Privacy & Security. Approve these yourself with Touch ID or your Mac password. Enable Input Monitoring only if RustDesk requests it.

Quit and reopen RustDesk if macOS asks. Do not share your Mac password with support.

3. Connect to CREATE SOMETHING

Open server-config.txt from this folder in TextEdit. Choose Edit → Select All, then Edit → Copy.

In RustDesk, open the menu next to your ID → Settings → Network → Unlock network settings → ID/Relay server. Approve the local authentication prompt, click the clipboard icon beside the dialog title to import, then click OK.

The configuration contains the server address and public key, not a password.

4. Start a session with Micah

At the agreed time, share your RustDesk ID and the current one-time password directly with Micah. Approve any connection prompt. Keep RustDesk open and your Mac awake during the session. You personally approve any OAuth sign-in or account permission request.

Do not set a permanent password for this setup. Only share the one-time password for a session you requested.

5. Check it works, then end access

For the first session, confirm Micah can see your screen, move the pointer, and type in a blank TextEdit document. Close the session and choose RustDesk → Quit RustDesk. Confirm Micah’s connection ends. Closing just the window may leave the app running.

Keep RustDesk closed between sessions. To remove its permissions entirely, turn off RustDesk’s Screen Recording and Accessibility permissions in System Settings. Contact Micah if RustDesk does not show Ready or a permission prompt persists.
