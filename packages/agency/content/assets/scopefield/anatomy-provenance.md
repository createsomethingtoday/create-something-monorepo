# Scopefield isometric story

Original CREATE SOMETHING conceptual drafting station: full-width page surface, rail-mounted review tray, visible human decision control. This is not an app screenshot, recording, or claim that public agent execution exists.

Drawing reference: Anatomy, https://github.com/wheresryan22/anatomy, pinned at e6600ffc4e8e6620eeb45bf49bcdbd5e4b84163f. Reviewed SKILL.md, references/craft.md, references/motion.md and kit/iso-kit.mjs. No upstream scripts were executed and no dependency was installed. Only the compact projection math is adapted; geometry, page design, controls and copy are original. MIT notice (Copyright (c) 2026 Ryan) retained at static/licenses/anatomy-MIT.txt.

Parts: four feet, base, top inset, two drawer rails, four risers, page chassis, page inlay, browser header, three marks, image field, heading, four text rules, three content blocks with six rules, tray base/inset/three walls/paper/heading/five rules/handle, control deck/ruler/twenty ticks/switch plate/two control blocks, four screw heads and cores. Lines on the page represent conceptual printed content; they do not reproduce product UI. Structure uses fixed isometric projection, solid face tones, and attached supports. The tray slides on rails; the control strip becomes prominent at the third native-scroll stage.

Core text is separate HTML. SVG is decorative. No timers, autoplay, WebGL, 3D runtime or pointer-following effect. IntersectionObserver selects one stage; CSS transitions settle. Pause, reduced motion and no JavaScript preserve the complete stable composition. Public beta1 remains the only download. Synthetic practice is explicitly separated from public-agent capability.
