# Delivery OS Engagement Hub Template

Use this as the top-level client page.

## Hero

- engagement name
- client name
- one-sentence summary
- what is live now
- primary CTA or review action

## Overview

- what is being delivered
- why it exists
- current state
- next decision needed from client

## Execution snapshot

- active components
- current milestone
- blockers
- required client inputs this week
- live links

## Product pack

- PRD
- onboarding
- timeline
- walkthrough video
- support guide

## Commercials

- contract link
- invoice link
- ongoing management terms
- approval path

## Operator handoff

- access checklist
- integrations
- deployment/runbook links
- support/escalation path

## Open questions

- unresolved decisions
- items waiting on client
- items waiting on operator
