## Gesture vocabulary

The six stills show Welcome, Attention, Focus, Review, Pause and Handback.
Focus looks down at the notebook; Review supports a sheet for inspection.
Pause raises a gentle palm toward the viewer. Handback offers the notebook
forward in both hands. These two gestures were refined after independent
review found their earlier versions insufficiently distinct.

The owning application supplies truthful words and explicit controls. Focus
means attention, not proof of execution. Review asks for a decision without
granting approval. Pause preserves room for a next step without claiming a
repair. Handback offers an artifact without asserting success.

The sample route changes local text and selection only. It never starts a live
tool, detects activity or claims an external receipt. The r42 head remains the
same in every state; the six body poses appear in an editorial gallery below.
There is no timer, automatic expression transition or perpetual busy indicator.

Before hydration, the select and sample buttons are disabled. Without
JavaScript, the explanation, artwork and native comparison disclosure remain
available. These modules are private local examples, not public package exports.
