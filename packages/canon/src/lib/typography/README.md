# Canon Typography Components

Typography components anchor page-level claims and editorial rhythm.

## Examples

```svelte
<script lang="ts">
	import { TypographyHero } from '@create-something/canon/typography';
</script>

<TypographyHero
	eyebrow="Canon"
	title="Make the claim readable first."
	description="Use type to clarify hierarchy, proof, and next action."
/>
```

## Accessibility Evidence

- Hero-scale type belongs only at route or section boundaries.
- Keep supporting text readable and avoid relying on scale alone for hierarchy.
