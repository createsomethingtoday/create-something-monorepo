# Review checklist

- [ ] Reader question and boundary stated; schematic/inferred/measured status visible.
- [ ] Each assembly and edge maps to evidence or a declared design assumption.
- [ ] Stable IDs, unique names, valid endpoints, and same topology across every view/mode.
- [ ] Exterior occludes; transparency preserves shell; cutaway specifies removed region; explosion retains identity and connections.
- [ ] Shared scale, upright labels, consistent legend and selection; no false physical units.
- [ ] Correct painter order inspected; no misleading intersections at ports or enclosure.
- [ ] Contract declaration distinguished from enforcement; approval scope and refusal represented where execution is illustrated.
- [ ] Verification and receipt remain separate; unknowns and failed checks are not styled as success.
- [ ] Color meanings declared and redundant in text; no synthetic quantitative heat maps.
- [ ] Keyboard, touch, mobile, zoom, no-JS, print and reduced-motion checked.
- [ ] Console errors, network requests, DOM/byte budgets and render timing recorded.
- [ ] Desktop/mobile and key mode screenshots inspected; limitations reported.
- [ ] Original source and upstream attribution included; no installation or publishing implied.
