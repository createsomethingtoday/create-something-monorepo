# Graphite Motion

Repo-owned Codex plugin for short organic learning animations. The plugin root is `graphite-motion/`; its manifest is `graphite-motion/.codex-plugin/plugin.json`.

- **Warm paper:** original graphite artwork and established motion rules.
- **PRIVATE / White Pencil:** off-white pencil on PRIVATE black, with a dedicated three-frame sprite, still captions, restrained movement and a static learning alternative.

Start with [the skill](graphite-motion/skills/graphite-motion/SKILL.md). The [PRIVATE style reference](graphite-motion/skills/graphite-motion/references/white-pencil.md) contains the dark-mode contract. The [verified study](../../docs/examples/draw-storytelling/private-white-pencil/README.md) includes editable source, video, storyboard and generation instructions.

Version 0.2.0 packages both modes. It requires no service configuration or credentials. Register this folder through your Codex plugin installation workflow; this repository addition does not change a user's marketplace configuration. Creating an animation does not authorize publishing it.
