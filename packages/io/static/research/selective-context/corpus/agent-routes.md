# Finding evidence

> Source snapshot range (UTC): 2026-10-01T00:00:00.000Z to 2026-10-01T00:00:00.000Z.

## Local search

Begin with a bounded lexical search, inspect the cited passage, then read its canonical source. No semantic model or remote ranking is needed for ordinary orientation.

## Historical context

History explains prior rationale but does not verify current state. Historical excerpts remain private. Current source evidence governs claims about what is live.

## No match

An empty result should send the reader to the index and ordinary file search. Do not invent an answer or quietly widen access when no passage matches.
