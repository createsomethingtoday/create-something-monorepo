# Record ownership

> Source snapshot range (UTC): 2026-10-01T00:00:00.000Z to 2026-10-01T00:00:00.000Z.

## Record truth

Substrate stores the canonical workshop records. Atlas supplies a visual canvas for orientation. A diagram helps locate evidence; it does not replace the owning record.

## Decision ownership

The operator owns the release decision. A search hit provides descriptive evidence and cannot grant permission to deploy or send a notification.

## Three layers

Database holds facts, Automation executes bounded operations, and Judgment decides whether the evidence is sufficient. Keep these responsibilities separate.
