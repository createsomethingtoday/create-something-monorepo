# LTD Canon Philosophy Overlay Surface Policy

This policy keeps @create-something/ltd overlays portable across web, chat, app, voice, glasses without forking Canon.

## Web

- Use Canon components and tokens first.
- Add project-local layout, copy, and theme aliases only when the consuming route needs them.
- Keep receipt, evidence, and owner metadata visible near decisions.
- Route families: `/canon`, `/standards`, `/voice`, `/principles`, `/taste`, and presentation/documentation routes.
- Full philosophy, standards, contribution context, and cross-links belong on web routes.

## Chat

- Return compact summaries grounded in overlay artifacts.
- Name the registry item or template before suggesting a local primitive.
- Route primitive changes through Canon extension intake.
- Prefer checked-in Canon markdown and content-loader metadata over route scraping.
- Answer with the relevant Canon route, source file, state, proof, and next action.

## App

- Preserve touch targets, focus order, and text state labels.
- Use local templates for workflow-specific screens, not new base components.
- Translate philosophy into checklists, decision panels, proof strips, and owner/action states.
- Keep standards review usable without requiring the operator to parse long prose.

## Voice

- Speak status, owner, and next action.
- Do not read long policy text. Point to the receipt or durable record.
- Summarize the Canon standard or philosophy point in one short sentence, then name the route for full context.

## Glasses

- Show only glanceable state, owner, and next action.
- Keep reasoning, review history, and policy bodies on larger surfaces.
- Show route, state, owner, and next action only; do not show full philosophy, standards prose, or contribution policy.

## Promotion Boundary

Project overlays can become Canon candidates only after repeated-surface evidence exists. Until then, keep implementation, copy, and policy local to the named overlay.
For LTD, promote the reusable documentation structure only. Keep property identity, philosophy language, presentation copy, and taste examples local.
