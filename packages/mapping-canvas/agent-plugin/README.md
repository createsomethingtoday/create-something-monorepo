# Draw agent plugin connection

The existing personal `draw-motion-descript` plugin bundles the adapter in `../scripts/draw-agent.py` and the `skills/draw-agent` skill. Update it with `python3 packages/mapping-canvas/scripts/install-agent-plugin.py /Users/micahjohnson/plugins/draw-motion-descript`, validate, run the Plugin Creator cachebuster helper, and reinstall `draw-motion-descript@personal`. The installer preserves narration scripts/configuration and other MCP servers.

The stdio adapter requires Python 3, uses no third-party dependencies, and connects to Draw's bounded `/api/agent` API. WebMCP continues using the same underlying browser tool instances. An open project and explicit one-time pairing code are required; this is delegated access to a device-local project, not authenticated account identity or a cloud project store. Agent names are self-reported.

The browser keeps its project capability in tab-scoped session storage for at most 24 hours. The adapter stores its separate capability in a mode-0600 file outside the installed plugin. Server records store capability hashes, a schema catalog, short-lived command payloads/results, and expiry. Pairing codes contain 256-bit random secrets, expire after ten minutes, and can be consumed once. Browser actions require same-origin requests; agent actions require the separate agent capability. Creation/pairing use the existing server-side rate-limit secret. Disconnect revokes server access and removes pending command payloads/results.

Commands are claimed atomically once. A missing acknowledgement becomes `unknown`, never automatic replay. Stable command IDs retain an argument hash so ID reuse with different arguments is rejected even after completion. Receipts expire after ten minutes; physical cleanup is lazy on subsequent authorized poll/create traffic, so this is an access expiration guarantee, not an exact physical deletion deadline. Session expiry is absolute, not extended by polling. Closed/background-throttled tabs report offline after fifteen seconds; agents must wait for the intended project to reconnect. One visible project mode supplies the current tool catalog.

Deployment: apply additive `0003_agent_connections.sql` to existing DRAW_DB before deploying the matching Pages build. Existing DRAW_SHARE_RATE_SECRET also gates connection creation. Rollback to the previous Pages build leaves unused tables without changing existing canvas/share data. No new secret, account provider or paid service is required.

Verification must use the installed transport and actual in-app browser: pair; inspect; compose/edit; see activity; undo; reload; continue; change Canvas/Motion; revoke and require subsequent agent denial. Test target isolation, expiry, command duplication and uncertain outcomes independently. Do not substitute an injected WebMCP shim.

## Fast execution and bounded intent

The adapter exposes `draw_agent_run` for explicit edits and `draw_agent_intent` for bounded Jev routing. Both converge on the same browser `draw_execute` tool; see [contract and recovery](../docs/fast-execution.md). Explicit execution needs no model credential. Optional intent routing uses the existing Infisical development TypeSafe credential in the adapter process (or an explicitly supplied environment key), never the browser. The installer copies both Python modules and the updated skill. Reload the MCP connection to expose new tools; the installed CLI works immediately.

The live routing diagnostic is opt-in because it uses TypeSafe API requests: `DRAW_TYPESAFE_INFISICAL=1 python3 packages/mapping-canvas/scripts/verify-draw-intent.py --output /tmp/draw-intent-pilot.json`. It reports safe outcomes separately from supported requests that executed; abstention is safe but does not count as successful fast-path coverage. Keep failed runs when changing prompts and use new held-out requests before drawing broader conclusions.
