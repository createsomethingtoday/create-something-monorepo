# VCSL Upright Knight — workflow reel subset

This folder contains the fourteen VCSL Keys samples used by the CREATE
SOMETHING workflow reel: seven soft-velocity sustains and their seven release
samples. They come from Versilian Studios' Upright Piano, Knight instrument.

VCSL Keys is dedicated to the public domain under CC0 1.0. The source page is
<https://versilian-studios.com/vcsl-keys/> and the CC0 legal text is available
at <https://creativecommons.org/publicdomain/zero/1.0/legalcode>.

`manifest.json` records the official archive URL and hash, the upstream and
local paths for every selected sample, the original SFZ mapping values, and the
SHA-256 of every committed file. Attribution is not required by CC0, but the
source is preserved here for provenance.

The subset is intentionally reel-specific. Do not expand it into the complete
VCSL library without a separate storage and product decision.
