# Agentic engineering creator design review

Audience: independent technical educators, agent builders, researchers, and their learning communities. Decision: is an owned private content network the right home for the creator's teaching?

## Findings and implementation

The original page communicated a generic video-membership offer. Its decorative cover did not explain the technical creator use case, and its primary illustration sent visitors to an empty library. The library had no search or series filter; creator labels assumed films rather than technical sessions.

The four-chapter page now moves from technical creator fit, to an interactive illustrative network, to ownership/access scope, to discovery. The hero diagrams creator -> publish -> controlled access -> audience. Its primary CTA explicitly remains a managed build conversation. The preview lets visitors choose an academy, collective, or research circle, change its name, and compare access models. Example lessons are labeled non-playable; editing never provisions accounts or saves server data.

The library filters only metadata already authorized by the server, with search, series selection, result count and clear-filter recovery. The creator workspace uses walkthrough/session language. Authentication and media policy are unchanged.

## Design contract

Use Canon Performance paper, ink and signal-soft tokens; retain the existing house sans/editorial/mono typography. Native radio controls, labels and select retain keyboard behavior. No motion is required. No fake member counts, live telemetry, testimonials, or content-completion claims. Other-modality overlay policies do not imply shipped clients.

Mobbin was unavailable in the session tool inventory. No external precedent is claimed. Sources: rendered preview, Canon house rules, Performance Lab visual grammar and page-sharpness contract.

## Evidence

Preview browser at desktop 1440px and mobile 390px: rendered views inspected, no horizontal overflow. Changing the format updates lessons; custom name updates heading; public-preview selection updates the first lesson access label. Arrow-key radio selection works. Package check reports zero errors/warnings; 25 tests include multi-term/series filtering and preserve existing API/access tests. Actual signed-in library and Stream playback still require the original live acceptance; illustrative UI does not replace those checks.
