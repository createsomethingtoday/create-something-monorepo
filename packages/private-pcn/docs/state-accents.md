# PRIVATE state accents

PRIVATE retains the dark Performance product shell. Semantic colors are local aliases to Canon Performance soft tokens: signal (information/action), growth (success), gold (review/attention), risk (failure). Neutral draft/archive/access states use the existing muted token. No new palette, learning completion claims, access grants, or payment configuration.

`StateBadge` pairs an explicit label with a decorative icon. `StatusNotice` provides polite status announcements, or an alert for errors; processing uses a loading icon that stops under reduced motion. Focus includes native disclosure summaries. Disabled buttons no longer imply that a request is running.

- Access (Members / Public preview / Private), publication (Draft / Published / Archived), and ingestion (Video ready / Processing failed) are independent.
- Creator approved is scoped to admission. Company support approval remains separate.
- In review, Changes requested and Suspended need attention; they are not network or transport failures.
- Saved confirms persistence, not correctness, learner competence, or publication.
- Playback and mutation failures are errors. Unknown/pending purchase outcomes remain informational; refunds/disputes need attention.
- Impersonation remains a persistent amber banner with target, expiry, audit reminder and exit. No permission changes.

Apply through the shared components in lessons, the publishing desk, creator admission/review, dashboard and asset catalog/detail. Keep badges compact and surfaces mostly neutral. Use labels and icons as well as color; verify contrast against the actual composited surface, keyboard focus, narrow layouts and reduced motion before promotion.
