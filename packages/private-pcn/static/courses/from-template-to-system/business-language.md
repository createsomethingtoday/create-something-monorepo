# Stillwater Workshop — design-language draft
Voice: concrete, calm, attentive. Explain the process; avoid “timeless excellence” and unsupported craft claims.
Hierarchy: visitor job first; services second; synthetic work examples third; request next.
Color roles: off-white background; charcoal foreground; muted moss accent. Verify actual combinations against contrast requirements before use.
Type: keep the template's licensed families where practical; readable body and restrained headings. No new paid fonts assumed.
Spacing: use the template's existing scale; one consistent rhythm across services and projects.
Images: original or licensed still-life furniture photos; label synthetic project stories. Never imply depicted work is a real customer commission.
CTA: Request an assessment. Form confirmation: “This is a demonstration. No request was sent.”
Checks: every page has an unambiguous next action; no empty placeholder links; mobile text does not clip; focus remains visible; all claims have a source or synthetic label.
