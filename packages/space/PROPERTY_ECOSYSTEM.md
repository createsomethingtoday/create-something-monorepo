# Create Something — Property Ecosystem

## Philosophy: Modes of Being

Each domain represents a distinct "mode of being" in the Create Something world. Together, they form a complete system where reading informs doing, doing informs building, and building tests philosophy.

## The Properties

### createsomething.space — **Do**
**The workbench. Build, test, analyze.**

**Purpose:** Live tools for automation infrastructure development

**What happens here:**
- Execute code in Cloudflare Workers runtime
- Learn integration patterns through graded challenges
- Analyze CSS animations from any URL
- Explore live data dashboards
- Browse via terminal interface

**User journey:**
- "Let me test this pattern..."
- "How does this animation work?"
- "Show me the live data..."

**Value proposition:** Interactive tools that run on real infrastructure. Not articles about tools — the tools themselves.

**Relationship to others:**
- **Distinct from .io** — .io documents, .space does
- **Precedes .agency** — Test tools before building for clients
- **Validates .ltd** — Proof of infrastructure capability

---

### createsomething.io — **Read**
**The research layer. Papers, patterns, documentation.**

**Purpose:** Technical documentation, research papers, and MCP patterns for builders

**What happens here:**
- Deep-dive research papers
- MCP server patterns and reference implementations
- API documentation and guides
- Experiment results and methodology

**User journey:**
- "How does this work?"
- "What's the best pattern for..."
- "Show me the research..."

**Value proposition:** Comprehensive technical knowledge with real evidence. Papers, not blog posts.

**Relationship to others:**
- **Distinct from .space** — .io documents, .space does
- **Supports .agency** — Knowledge enables client work
- **Documents .ltd** — Technical authority and expertise

---

### createsomething.agency — **Build**
**The implementation layer. Ship for clients.**

**Purpose:** Custom MCP development and automation infrastructure services

**What happens here:**
- Custom MCP server development
- Intelligence Layer (Skills and Agents)
- MCP audit and strategy
- Production deployments

**User journey:**
- "We need this built..."
- "What MCPs would unlock value for our business?"
- "Build the connectivity layer..."

**Value proposition:** The creation moat as a service. Custom MCP development that templates can't provide.

**Relationship to others:**
- **Uses .space** — Tools tested there inform client work
- **References .io** — Documentation supports delivery
- **Operates under .ltd** — Legal entity for contracts

---

### createsomething.ltd — **Philosophy**
**The standard. Why creation matters.**

**Purpose:** The philosophical foundation for automation infrastructure

**What happens here:**
- The Subtractive Triad (DRY, Rams, Heidegger)
- The MCP-First Thesis
- The Automotive Framework
- Why creation > consumption

**User journey:**
- "Why do you build this way?"
- "What are your principles?"
- "What is the creation moat?"

**Value proposition:** The philosophy that guides everything. Not marketing — conviction.

**Relationship to others:**
- **Guides .space** — Principles determine what tools to build
- **Informs .io** — Philosophy behind the research
- **Directs .agency** — Standards for client work

---

## The Hermeneutic Circle

```
.ltd (Philosophy) → principles →
.io (Research) → validated patterns →
.space (Workbench) → proven tools →
.agency (Services) → outcomes →
.ltd (Philosophy) → refined by what works
```
