# Quality Rubric

Source: https://webflow.com/templates/grading-rubric

Three tiers. The bar to pass is **Good** on every dimension. "Satisfactory" gets feedback and one revision round. Below Satisfactory is a reject.

## Design Criteria

### Overall UX

| Tier | Standard |
|------|----------|
| Satisfactory | UX serves its purpose despite lacking some visual best practices. Not 100% intuitive. |
| Good | UX feels better-than-average. Free of elements that confuse, strain, or distract. |
| Exceptional | UX is purely delightful. Shows mastery of visual design best practices. |

### Graphic Design

| Tier | Standard |
|------|----------|
| Satisfactory | Visuals may lack originality and technical quality. Dated appearance. |
| Good | High-quality, relevant, aesthetically pleasing, strategically placed. |
| Exceptional | High-quality, innovative, stunning. Demonstrates mastery. |

### Typography

| Tier | Standard |
|------|----------|
| Satisfactory | Legible/readable but may need better hierarchy. |
| Good | Legible/readable, good hierarchy, meets submission guidelines. |
| Exceptional | Hierarchy implemented perfectly. Meets all submission guidelines. |

### Interaction Design

| Tier | Standard |
|------|----------|
| Satisfactory | Interactions superfluous in some areas. At times distract more than engage. |
| Good | Interactions help direct the user and promote information processing. |
| Exceptional | Treated as brand attributes with personality. Reduce cognitive load. |

## Layout and Structure

### Hierarchy

| Tier | Standard |
|------|----------|
| Satisfactory | Fully processing information takes some effort. |
| Good | Fully processing information on the site feels easy. |
| Exceptional | Empathizes with the end user. Feels effortless, even fun. |

### Layout Design Quality

| Tier | Standard |
|------|----------|
| Satisfactory | Nearly all layout requirements implemented. May appear crammed or cluttered. |
| Good | Good variety from page to page. Consistent spacing. |
| Exceptional | Everything is functional and behaves as expected. |

### Responsive Design

| Tier | Standard |
|------|----------|
| Satisfactory | Fully responsive with a minimal number of bugs. |
| Good | Fully responsive with no more than 2 bugs. |
| Exceptional | Fully responsive with no bugs or other visual hierarchy issues. |

## Functionality Criteria

### Conversion Best Practices

| Tier | Standard |
|------|----------|
| Satisfactory | Action items not immediately obvious. Not hard to find. |
| Good | Good implementation. Easy to convert without the need to dig. |
| Exceptional | Expertly implements conversion-centered design. Effortless for the user. |

### Site Optimization (PageSpeed Insights)

Run at https://pagespeed.web.dev/?url=&lt;template-url&gt;

| Tier | SEO | Performance | Best Practices |
|------|-----|-------------|----------------|
| Satisfactory | 51-70 | 51-70 | 51-70 |
| Good | 70-90 | 51-70 | 51-70 |
| Exceptional | 90-100 | 70-90 | 70-90 |

### Accessibility

| Tier | Standard |
|------|----------|
| Satisfactory | Accessibility score of 51-70 |
| Good | Accessibility score of 70-90 |
| Exceptional | High legibility, passing contrast ratios. Near total adherence to WCAG. |
