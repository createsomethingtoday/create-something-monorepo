# Reviewer language

Name the exact submission, version, current status and action. Approval, rejection, requested changes and developer messages require a separate confirmation. Distinguish local fixtures, static findings, actual runtime evidence and not-tested behavior. API usage is billed separately; work-account sign-in is not a ChatGPT model entitlement. Zendesk uses the support integration attribution; the initiating reviewer is retained in portal receipts. Unknown outcomes require reconciliation, never a claim of success.
