# Surface policy

## Web

The implemented Next.js portal uses the official Webflow light design tokens and Inter, as requested by the owner. Canon supplies the repository's signal/decision/proof policy structure, not a competing visual theme. Preserve private bundles, individual work-account identity, explicit action confirmation, 44px mobile controls, focus isolation, and artifact/provider evidence.

## App

The responsive browser layout is implemented. No native application is shipped. Future app surfaces must retain the same identity, authorization, evidence and confirmation controls.

## Chat

No new ChatGPT application ships with this portal. A future chat handoff may summarize an authorized user's receipts and untested behavior; it must not infer tool access from another user's session.

## Voice and glasses

Not implemented. These modality entries are policy constraints, not availability claims. Future summaries should expose only permitted status and next steps. Decisions and developer sends must return to a surface where the user can inspect and confirm exact content.

## Promotion boundary

This is a local Webflow-branded surface. No shared Canon primitive or token-scale change is proposed. Live OAuth and paid inference acceptance remain separate release gates in VERIFICATION.md.
