# Review handoff contract

A review handoff names the submission/version, owner, exact bundle SHA-256, provider model and response ID, executed commands and outcomes, static findings, and behavior not tested. Link the durable receipt. A finding is not an approval. For an uncertain action, attach current provider evidence and the explicit reconciliation observation; do not replay the write.

The current implementation and test boundaries are in `../../VERIFICATION.md`. This contract describes the shape of a handoff and contains no executable placeholders.
