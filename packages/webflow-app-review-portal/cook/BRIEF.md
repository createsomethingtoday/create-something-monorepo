# App Review portal Cook brief

Target: a Webflow light review dashboard with individual MCP OAuth, explicit review decisions and developer messages, private bundles, and isolated API analysis.
Reference: official Webflow Apps design guidelines and light design tokens. Component language is the reference; this is not a pixel recreation.
Rubric: subjective layout, hierarchy, typography/components, color and apparent usability, target 9/10. Functionality is tested separately.
Scope: bounded continuation of the existing App Review Site work. Original Site is preserved. The user authorized the recommended Webflow Cloud portal, including preview publication. No costly media render is involved.
Boundaries: no live decisions or developer messages for smoke testing; no teammate invitations; missing identity configuration fails closed. Model access requires a separately funded API account.
Evidence: local fixture stills, independent critics, source tests and live anonymous-denial verification. No claim of successful live OAuth or paid inference.
