We updated the Webflow Way Validator app. The report is shorter and shows what to fix first. The checks, the findings and the score did not change.

You do not need to install anything. You get version 1.3.14 the next time you launch the app in the Designer.

One result at the top

The top of the report shows if you can submit, the number of errors, warnings and notes, your score, and the next step. Categories with errors come first. Categories with no findings fold into one line.

A run shows its progress

During a run you see a progress bar and the current step.

A Fix List that is faster to read

The Fix List has every error that blocks your submission, with the fix and the page for each one. Use the checkboxes to track your work, then run the Validator again to confirm the fixes.

Other changes

  • Before the first run on a site, the panel shows the three steps to a result.
  • The Options menu fits the panel. "Current page only" was cut off before.
  • Small text is larger and has more contrast.

Reminder: the Template CLI

The Template CLI runs the same checks from your terminal. You do not need the Designer open, and you do not need the Validator script on your site. A complete run with a 100% pass counts for the template submission form, the same as a pass from the app.

  1. Install with Node 20 or later. Run the same command again to update.
    npm install -g https://validation-worker.createsomething.workers.dev/cli/wf-template-validate.tgz
  2. Sign in to Webflow, then find your site ID.
    wf-template-validate login
    wf-template-validate sites
  3. Publish the template site, then run all checks and record the result.
    wf-template-validate validate https://your-template.webflow.io --site <site ID>
