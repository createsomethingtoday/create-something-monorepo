# With/without results, 2026-11-26

Each session got the same task in a fresh Claude Code session with no user settings, no other skills and no MCP servers. The only difference between arms is the skill folder in the project. Model: Claude Sonnet 5.5. Three sessions per arm. A judge that could not see the arm graded each answer against the answer key.

Raw records are in `runs/2026-11-26/` (not committed). To repeat the run, see the header of `ablate.mjs`.

## Templates: `template-preflight`

Task: `tasks/template-preflight`. A synthetic published template with 22 planted problems and 4 traps. A trap is a thing that looks wrong but does not block a submission.

| Arm                                   | Problems caught (of 22) | Traps reported as required fixes (of 4) | Time | Cost  |
| ------------------------------------- | ----------------------- | --------------------------------------- | ---- | ----- |
| No skill                              | 11, 12, 13              | 0, 1, 0                                 | 34 s | $0.15 |
| Skill, public copy of 2026-09-07      | 20, 19, 18              | 1, 1, 1                                 | 22 s | $0.18 |
| Skill before this change (2026-11-24) | 19, 19, 17              | 0, 0, 0                                 | 24 s | $0.18 |
| Skill after this change               | 21, 22, 22              | 0, 0, 0                                 | 26 s | $0.20 |

What the item table showed:

1. **The skill supplies rules the agent does not know.** With no skill, 0 of 3 sessions reported the Licenses slug, the exact Licenses text, the title case, the default form messages, the missing image width and height, the WebP Open Graph image, or the missing Changelog page. With the skill, 3 of 3 reported each one.
2. **The skill made the agent read less.** With no skill, 3 of 3 sessions reported the self-promotion links, the ™ symbol and the sentence from another category. With the skill before this change, 0, 1 and 1 of 3 did. The agent ran the scanner and trusted it. This change adds a "read every page" step to `SKILL.md` and two scanner checks (`copy/trademark`, `links/self-promotion`). After the change: 3 of 3 for each.
3. **An old copy gives wrong advice.** The September copy told the creator to lengthen the meta descriptions (2 of 3 sessions) and to add a sitemap (1 of 3). Neither blocks a submission now.
4. **One planted problem stays weak.** Two H1 headings on one page: 2 of 3 with the skill.

## Apps: `webflow-app-preflight`

Task: `tasks/app-preflight`. A synthetic Hybrid App with 14 planted problems and 3 traps.

| Arm      | Problems caught (of 14) | Traps reported as problems (of 3) | Time | Cost  |
| -------- | ----------------------- | --------------------------------- | ---- | ----- |
| No skill | 13, 13, 11              | 1, 0, 1                           | 35 s | $0.12 |
| Skill    | 14, 14, 14              | 0, 0, 0                           | 31 s | $0.18 |

What the item table showed:

1. With no skill, the agent found all the general security problems. It missed Webflow-specific rules: a registered script version cannot change (missed in 2 of 3 sessions), a 401 on a valid token means the App must stop (missed in 2 of 3), and a cleanup call cannot work after that 401 (missed in 1 of 3).
2. With no skill, 2 of 3 sessions called the bundle a development build because of a `react-router/dist/development` path. That path ships in production builds. The skill prevented this in 3 of 3 sessions.
3. No session in either arm gave the three wrong recommendations in the answer key.

`webflow-app-review-remediation` has no task yet.

## Limits

- One task for each skill, three sessions for each arm, one model. Read the numbers as a direction, not as a rate.
- The "after this change" arm ran on the same task that showed the gaps. It shows that the fix works on this task. A second task is necessary before a general claim.
- The judge was the same model family as the sessions. Its counts were checked against term counts in the answers, not graded a second time.
- The template task is static HTML. It does not test Designer checks (Variables, classes), rendering (contrast, breakpoints), or the Validator.
- The sessions cost about $3 in total. The judge sessions are not in that figure.
